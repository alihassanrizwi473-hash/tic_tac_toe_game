# Tic Tac Toe Game 🎮
A Python-based Tic Tac Toe game where two players take turns marking spaces on a 3x3 board to win the game.

## Project Overview
Tic Tac Toe is a Python-based two-player game played on a 3x3 grid. Players take turns marking the board with X and O. The first player to get three marks in a row, column, or diagonal wins the game.

## Features
- Two-player gameplay.
- Interactive 3x3 game board.
- Turn-based player system.
- Automatic winner detection.
- Draw detection.
- Simple and user-friendly gameplay.

## Technologies Used
- Python

## Game Rules
- Player 1 uses X.
- Player 2 uses O.
- Players take turns selecting an empty position.
- The first player to complete a row, column, or diagonal wins.
- If all positions are filled without a winner, the game ends in a draw.

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python tic_tac_toe_game.py
```
